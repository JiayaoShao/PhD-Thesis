# Chapter 3: Fourth-Order Euler-Lagrange Method

This branch contains the numerical implementation and plotting script for the **Fourth-Order Euler-Lagrange Method** presented in **Figure 3.5** of the PhD thesis.

---

## 1. Reproducing Figure 3.5

* **Computation (MATLAB):** Run `EL_2DwithLineSearch.m` to generate the optimal action trajectories using the Fourth-Order Euler-Lagrange method with line search.
* **Data Storage:** The computed simulation outputs are saved in the `EL/` folder.
* **Plotting (Python):** Run `MAM.py` to generate **Figure 3.5** using the data stored in `EL/`.

---

## 2. File Structure Overview

* **`EL/`**: Folder containing computed data for Figure 3.5.
* **`EL_2DwithLineSearch.m`**: MATLAB script to perform the Fourth-Order Euler-Lagrange computation with line search.
* **`MAM.py`**: Python script to visualise and plot Figure 3.5.
* **`LICENSE`**: License file.
* **`README.md`**: Documentation file.
